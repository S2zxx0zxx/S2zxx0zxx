## `08` How I think about building

<table>
<tr>
<td width="33%" valign="top">

### Useful > impressive
A small product solving a real problem is more valuable than a complicated system built only to look advanced.

</td>
<td width="33%" valign="top">

### Evidence > claims
Build results, tests, deployment, audits, and actual product behavior matter more than a long technology list.

</td>
<td width="33%" valign="top">

### Iteration > perfection
Ship a solid version, inspect what breaks, learn from it, then make the next version meaningfully better.

</td>
